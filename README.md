# imbecile249.github.io

Личный сайт на GitHub Pages. Для локального просмотра в VS Code откройте папку
репозитория на ветке `site-v2` и запустите **Open with Live Server** для
`index.html`. Обычно сайт доступен по адресу <http://127.0.0.1:5500/>.
Сборка и установка зависимостей не нужны.

Старая версия на момент создания `site-v2` сохранена в коммите `cd16935`.
До объединения веток её также можно открыть, переключившись на `main`
в GitHub Desktop. Перед переключением сохраните правки в коммите `site-v2`.
